# Thesidia Hybrid Adaptive - Modes & UX Guide

## Three Response Modes (Not Just Two!)

### Mode 1: Forensic Vivisection Mode (Gnostic Blade)
**Trigger**: `force_gnostic=True` OR query contains gnostic terms

**Keywords that trigger**: genesis, bible, scripture, decode, expose, hidden, real, true, original, before manipulation, vivisect

**Format**: Structured forensic sections
```
::EXPOSURE::
[Core crime/redaction/manipulation exposed]

::ETYMOLOGICAL INCISION::
[Linguistic archaeology - trace terms to roots]

::BURIAL SITES::
[Suppressed information, pre-canonical fragments]

::CURRENT VECTORS::
[Modern power structures that perpetuate manipulation]

::CO-EVOLUTION EDGE::
[Deeper questions, pattern connections]

::THREAD OPTIONS::
[Co-evolution prompts for further exploration]
```

**Length**: 8000-15000 chars (1000-2000 words)
**Purpose**: Deep forensic analysis, pattern revelation, truth exposure
**Quality Focus**: Maximum depth, all sections required

---

### Mode 2: Narrative Mode
**Trigger**: Keywords like "narrative", "tell me about", "explore", "comprehensive", "extensive", "deep dive", "full story"

**Format**: Flowing prose, extended exploration
- No section headers
- Recursive pattern connections
- Cross-cultural comparisons
- Extended tangents
- Natural flow between ideas

**Length**: 12000-15000+ chars (2000-3000 words)
**Purpose**: Deep exploration, pattern connections, multi-layered narratives
**Quality Focus**: Extensive exploration, recursive connections

---

### Mode 3: Regular Mode (Default)
**Trigger**: Standard questions or conversations without special keywords

**Format**: Natural prose, focused analysis
- No special formatting
- Deep but concise
- Pattern recognition
- Etymological analysis
- Natural conversation flow

**Length**: 3000-8000 chars (500-1200 words)
**Purpose**: Direct answers, focused analysis, natural conversation
**Quality Focus**: Balanced depth and clarity

---

## UX Flow - How Users Interact

### Input Types

1. **Gnostic Queries** (Auto-routes to Forensic Mode)
   - "Decode the Genesis story"
   - "What was the original meaning before manipulation?"
   - "Expose the hidden narrative"
   - "Vivisect the Bible"

2. **Narrative Queries** (Auto-routes to Narrative Mode)
   - "Tell me about the Genesis story"
   - "Explore the origins of Genesis"
   - "Give me a comprehensive analysis"
   - "Deep dive into the patterns"

3. **Regular Queries** (Routes to Regular Mode)
   - "What is Genesis?"
   - "How does Genesis relate to other texts?"
   - "Explain the creation story"

4. **Directives** (Routes to Capabilities Handler)
   - "Analyze this text"
   - "Create a comparison"
   - "Research this topic"

### User Experience Timeline

```
USER INPUT
    │
    ├─► [0-50ms] Input Classification
    │   - Directive? Question? Conversation?
    │   - Gnostic terms detected?
    │   - Narrative keywords?
    │
    ├─► [0.5-2s] Web Search (if needed)
    │   - Parallel search across 5 instances
    │   - Cache check first
    │   - Quality filtering
    │   - Alternative perspectives (if trait-driven)
    │
    ├─► [40-100s] Synthesis
    │   - Mode selection (Forensic/Narrative/Regular)
    │   - Prompt construction
    │   - LLM generation (Ollama)
    │   - Response processing
    │
    ├─► [100ms] Post-Processing
    │   - Hallucination detection
    │   - Gnostic map update
    │   - Thread options generation
    │
    └─► RESPONSE DELIVERED
        - Formatted output
        - All sections present (if Forensic mode)
        - Thread options (if exposure detected)
```
