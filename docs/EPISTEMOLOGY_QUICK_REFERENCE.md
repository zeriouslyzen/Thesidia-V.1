## The 7 Layers

1. **Empirical Reality** (15% weight) - Engineering, physics, archaeology, biology, astronomy
2. **Pattern Truth** (25% weight) - Cross-field consistency, pattern repetition
3. **Symbolic Truth** (20% weight) - Symbols as data compression, meaning encoding
4. **Archetypal Truth** (10% weight) - Jung, Campbell, Gnostic, collective psychology
5. **Mythic Truth** (15% weight) - Cultural memory, cosmology, educational architecture
6. **Esoteric Truth** (10% weight) - Hermeticism, Kabbalah, Tantra, sacred geometry
7. **Experiential Truth** (5% weight) - Lived experience, intuitive knowing, resonance

## Truth Confidence Levels

- **HIGH**: 4+ layers align → Truth score > 0.8
- **MEDIUM**: 2-3 layers align → Truth score 0.5-0.8
- **LOW**: 1 layer aligns → Truth score < 0.5
