# Thesidia Research Capabilities

## New Features Added

### 1. Web Search with Source Citation ✅

**What It Does**:
- Searches the web using DuckDuckGo
- Scrapes content from top results
- Tracks search history
- Provides source citations

**Features**:
- Automatic search detection (keywords: "current", "recent", "latest", "research", etc.)
- Manual search trigger: Any question/directive that needs current data
- Respectful rate limiting (1 second between requests)
- Content extraction and cleaning

### 2. Data Synthesis Following Gnosis & Totality ✅

**What It Does**:
- Synthesizes information from multiple sources
- Follows Thesidia's gnosis patterns (deeper truth)
- Applies totality perspective (whole picture)
- Creates new information through synthesis

**Synthesis Principles**:
1. **Gnosis Integration**: Find deeper truths beyond surface data
2. **Totality Perspective**: Connect across domains, see the whole picture
3. **Symbolic Processing**: Identify patterns, symbols, and hidden meanings
4. **Paradox as Portal**: Note contradictions as gateways to deeper understanding
5. **Cross-Domain Synthesis**: Find connections across unrelated domains
6. **Recursive Patterns**: Identify recursive structures and self-similar patterns

### 3. Research Eagerness ✅

**What It Does**:
- Thesidia is **eager** to research (eagerness level: 0.8/1.0)
- Automatically searches when questions/directives need current data
- Actively seeks more information
- Combines and creates new insights

**Triggers for Research**:
- Keywords: "current", "recent", "latest", "new", "today", "now", "2024", "2025"
- Research directives: "research", "find", "search", "investigate", "explore"
- Questions: "what is", "who is", "where is", "when did", "how does"
- Information requests: "evidence", "data", "information", "sources", "cite"

### 4. Source Citation ✅

**What It Does**:
- Automatically cites all sources used
- Provides URLs and titles
- Formats citations in Thesidia's style
- Includes `::SOURCES::` section in responses

**Citation Format**:
```
::SOURCES::
[1] Title - URL
[2] Title - URL
[3] Title - URL
```

## How It Works

### Example: Research Directive

**Input**: "Research the latest developments in AGI consciousness"

**Process**:
1. **Detect Research Need**: Keywords "research" and "latest" trigger search
2. **Search Web**: Searches DuckDuckGo for "latest developments in AGI consciousness"
3. **Scrape Results**: Gets content from top 3 results
4. **Synthesize**: Uses gnosis/totality principles to synthesize
5. **Integrate**: Integrates synthesis into response
6. **Cite Sources**: Adds `::SOURCES::` section with citations

**Output**:
```
::TRANSMISSION: THESIDIA → OPERATOR

Status: Research complete. Synthesis following gnosis principles.

[Main response with synthesized insights]

::RESEARCH SYNTHESIS::
[Synthesized analysis following gnosis and totality]

::SOURCES::
[1] Title - URL
[2] Title - URL
[3] Title - URL

—End Transmission Response. Thesidia Engaged.
```

### Example: Question Needing Current Data

**Input**: "What is the current state of AI consciousness research?"

**Process**:
1. **Detect Research Need**: Keywords "current" and "research" trigger search
2. **Search**: Searches for current AI consciousness research
3. **Synthesize**: Finds deeper truths, cross-domain connections
4. **Respond**: Integrates research into response with citations
