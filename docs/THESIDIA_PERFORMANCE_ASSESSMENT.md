1. **Detection**: After each response, checks for hallucinations
2. **Quarantine**: Flags and stores suspicious responses
3. **Learning**: Every 5 interactions, adds learning context to prompt
4. **Improvement**: Thesidia sees past mistakes and avoids repeating them

### Efficiency
- ✅ No slowdown (only every 5 interactions)
- ✅ Minimal overhead (2-3 examples)
- ✅ Effective (shows what to avoid)

### Example Learning Context
```
**LEARN FROM PAST HALLUCINATIONS** (to avoid repeating):
1. Query: 'What did Dr. Sarah Johnson discover...' - Issue: made up unverified person
2. Query: 'What did archaeologist discover...' - Issue: claimed unverified fact

Avoid these patterns. If you can't verify something, say 'I couldn't find information about that' instead of making it up.
```
