# KX Cuts: Expression & Growth System

**Date**: 2025-01-XX  
**Section**: KX Cuts (Short-Form Content)  
**Philosophy**: Expression, Recognition, Growth, Connection  
**No Likes**: Only meaningful interactions that support expression and learning

## Executive Summary

KX Cuts is a short-form content space for **creative expression**, **skill development**, **arts**, **learning**, and **aesthetic modern videos**. It's a platform for **expression at the highest levels** and **meaningful conversations** across all creative and skill domains.

**Core Principles**:
- ❌ **No Likes** - Vanity metrics removed
- ✅ **Recognition** - Acknowledgment for quality expression and skill
- ✅ **Growth** - Feedback that supports improvement
- ✅ **Connection** - Learning together, sharing knowledge, collaboration

**Content Types**:
- Visual arts (painting, drawing, digital art)
- Movement arts (dance, yoga, tai chi, movement)
- Music and sound
- Craft and making
- Learning and teaching
- Skill demonstration
- Creative expression
- Aesthetic modern videos
- Organic, authentic expression

## Part 1: Core Interaction System

### 1.1 Replace Likes with Recognition

**Recognition** acknowledges quality expression and skill. It represents appreciation for:
- Skill level and progression
- Quality of expression
- Teaching and sharing value
- Depth of work
- Consistency and dedication

**Mechanics**:
- **Recognition Given**: Limited per day (e.g., 10-20 recognitions/day)
- **Recognition Received**: Tracked separately from given
- **Recognition Quality**: Weighted by giver's skill level in that domain
- **Recognition Display**: Show count subtly, emphasize **who** recognized (experienced creators' recognition carries more weight)

**Visual Design**:
- Replace heart icon with **recognition symbol** (subtle, elegant icon)
- Show count, but keep it minimal
- Highlight when an **experienced creator** recognizes your content
- Show recognition from people you follow or learn from

### 1.2 Growth System

**Growth** offers constructive feedback that supports improvement:
- Technique and execution
- Composition and form
- Expression and style
- Teaching and communication
- Skill development

**Mechanics**:
- **Growth Button**: "Support Growth" or "Share Insight" action
- **Growth Types**:
  - Technique insight
  - Composition feedback
  - Expression feedback
  - Teaching insight
  - General improvement
- **Growth Quality**: Weighted by giver's experience in that domain
- **Growth Display**: Show count + breakdown by type
- **Growth Feedback**: Creator can see insights shared and by whom

**Visual Design**:
- Growth icon (subtle, supportive symbol)
- Show count
- Breakdown by growth type
- Highlight insights from experienced creators

### 1.3 Connection System

**Connection** enables:
- Learning together
- Sharing knowledge
- Skill exchange
- Joint creation
- Mutual support

**Mechanics**:
- **Connect Button**: "Connect" or "Learn Together"
- **Connection Types**:
  - Learn together
  - Share knowledge
  - Exchange skills
  - Create together
  - Support each other
- **Connection Display**: Show connection requests/offers
- **Connection Quality**: Track meaningful connections

**Visual Design**:
- Connection icon (subtle, linking symbol)
- Show connection count
- Show active connection requests
- Highlight meaningful connections

## Part 2: Skill & Expression Progression

### 2.1 Expression Levels

**Expression Levels** represent skill and creative progression across domains:

**Levels**:
1. **Exploring** (0-100 points)
2. **Developing** (100-500 points)
3. **Practicing** (500-2000 points)
4. **Skilled** (2000-5000 points)
5. **Experienced** (5000-10000 points)
6. **Advanced** (10000+ points)

**Creative Domains**:
- Visual Arts (painting, drawing, digital, photography)
- Movement (dance, yoga, tai chi, movement arts)
- Music (instrument, composition, sound)
- Craft (making, building, creating)
- Writing (poetry, prose, storytelling)
- Teaching (sharing knowledge, instruction)
- Performance (acting, performance art)
- Custom domains

**Visual Design**:
- Subtle level indicator next to username
- Minimal, elegant badge (optional)
- Progress indicator (can be hidden)
- Domain tags showing areas of focus

### 2.2 Expression Points System

**Earning Expression Points**:

**Content Creation**:
- Post a cut: +10 points
- Post gets recognition from advanced creator: +50 points
- Post gets recognition from experienced creator: +25 points
- Post gets recognition from skilled creator: +10 points
- Post gets recognition from practicing creator: +5 points
- Post gets recognition from developing creator: +1 point

**Skill Progression**:
- Consistent practice (daily): +20 points/day
- Skill improvement (growth insights applied): +30 points
- Teaching/sharing (connections): +40 points
- Reaching new level: +100 points bonus

**Quality Multipliers**:
- High-quality content (AI-scored): 1.5x multiplier
- Original content (not repost): 1.2x multiplier
- Teaching/sharing content: 1.3x multiplier
- Consistent posting: 1.1x multiplier

**Quality Controls**:
- Spam/low-quality content: -50 points
- Inappropriate content: -100 points
- System abuse: -200 points

### 2.3 Creative Progression Tracking

**Track Progress In**:
- Specific skills and techniques
- Creative domains (e.g., "Painting", "Movement")
- Teaching and sharing ability
- Expression quality
- Consistency and dedication

**Visualization**:
- Progress timeline (optional, can be hidden)
- Milestone achievements
- Domain badges (subtle)
- Growth indicators

## Part 11: API Endpoints Needed

### 11.1 Recognition Endpoints

```python
# Give recognition
POST /api/cuts/{cut_id}/recognize
  - user_id
  - expression_level (for weighting)
  - creative_domain (for context)

# Get recognitions for cut
GET /api/cuts/{cut_id}/recognitions
  - recognition_count
  - recognitions_by_level
  - recognitions_from_experienced
  - recent_recognitions

# Get user's recognitions
GET /api/users/{user_id}/recognitions
  - recognitions_given_today
  - recognitions_given_limit
  - recognitions_received
  - recognition_quality_score
```

### 11.2 Growth Endpoints

```python
# Give growth insight
POST /api/cuts/{cut_id}/growth
  - user_id
  - growth_type
  - growth_feedback (optional)
  - creative_domain

# Get growth insights for cut
GET /api/cuts/{cut_id}/growth
  - growth_count
  - growth_by_type
  - growth_from_experienced
  - growth_feedback

# Get user's growth
GET /api/users/{user_id}/growth
  - growth_given
  - growth_received
  - growth_applied
  - improvement_tracking
```

### 11.3 Connection Endpoints

```python
# Request connection
POST /api/cuts/{cut_id}/connect
  - user_id
  - connection_type
  - message (optional)

# Get connections for cut
GET /api/cuts/{cut_id}/connections
  - connection_requests
  - active_connections
  - successful_connections

# Get user's connections
GET /api/users/{user_id}/connections
  - active_connections
  - connection_requests
  - successful_connections
  - teaching_balance
```

### 11.4 Expression Endpoints

```python
# Get user expression
GET /api/users/{user_id}/expression
  - expression_level
  - expression_points
  - creative_domains
  - progress_to_next_level

# Update expression points
POST /api/users/{user_id}/expression/update
  - points_earned
  - creative_domain
  - activity_type

# Get creative progression
GET /api/users/{user_id}/progression
  - skills_practiced
  - skill_levels
  - consistency_streak
  - next_milestones
```
